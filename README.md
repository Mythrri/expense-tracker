# 💰 AI Expense Tracker

A smart Expense Tracker web app that helps you track daily expenses and gives you AI-based saving tips in real-time.

Built by Mythrri.

## 🚀 Live Demo
https://mythrri.github.io/expense-tracker/

## ✨ Features
- Add Expense with Name, Amount & Category
- Live Total Spent Calculator
- Category Wise Tracking - Food, Travel, Shopping, Study, Other
- AI Tip Engine:
    - If Total > ₹5000 -> Warns to stop overspending
    - If Food > ₹500 -> Suggests cooking at home
    - If Total > ₹2000 -> Suggests to track daily
    - Else -> Motivates to stay in budget
- Clear All Expenses in 1 Click
- Mobile Friendly & Clean UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Rule-Based AI Logic for Smart Tips

## 📱 How To Use
1. Enter what you spent on - Ex: Food
2. Enter Amount - Ex: 200
3. Select Category - Ex: Food
4. Click **Add Expense**
5. See Total + AI Tip change instantly!
